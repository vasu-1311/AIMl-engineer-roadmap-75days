# AI/ML Engineer Roadmap — 75 Days

A complete, day-by-day roadmap for becoming an AI/ML Engineer, built entirely from free YouTube playlists. This is the exact plan I am following, shared here so anyone starting from scratch can use the same structure instead of randomly jumping between courses.

## Who this is for

Anyone who wants a clear, structured path into AI/ML — from Python-level DSA fundamentals all the way to Generative AI and Agentic AI systems — without having to figure out the order of topics themselves.

## Duration and daily commitment

75 days, roughly 8 hours a day, split into three fixed blocks:

- Morning: Data Structures and Algorithms (only the topics relevant to AI/ML interviews, not full competitive programming)
- Afternoon: Main track video lectures (ML, then DL, then GenAI, then Agentic AI, then FastAPI)
- Night: Hands-on practice — implementing the day's topic in code, not just watching

## What's covered, in order

1. **DSA with Python** — Arrays, Strings, Linked List, Stack/Queue, Recursion, Trees, Graphs, Dynamic Programming
2. **Machine Learning (100 Days)** — EDA, Feature Engineering, Regression, Classification, Ensemble Learning, Clustering
3. **Deep Learning (100 Days)** — ANN, CNN, RNN, LSTM, Transfer Learning
4. **Generative AI using LangChain** — Prompts, Chains, RAG
5. **Agentic AI using LangGraph** — Multi-agent systems, tool calling
6. **FastAPI** — Deploying ML models as real, working APIs

## How to use it

1. Download the Excel file and make your own copy.
2. Start at Day 1 and follow the three daily blocks in order — do not skip ahead, each phase builds on the one before it.
3. Mark each day's status as you complete it. The Progress Summary sheet updates automatically.
4. Use the DSA topics listed for each day as your practice list — they are specific named problems, not vague categories.

## Why this roadmap is structured the way it is

Most roadmaps online are just a list of playlist links. This one adds:

- A fixed daily time-slot schedule instead of an open-ended "watch whenever" plan
- DSA practice running in parallel every single day, rather than being left until after the ML/DL portion is done
- Only the DSA topics that are actually relevant to AI/ML interviews, cutting out advanced competitive-programming topics that don't apply to this role
- A tracker that separates DSA, main-track learning, and hands-on practice into independent, individually trackable items
